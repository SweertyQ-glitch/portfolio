# My Portfolio

## О проекте

Это мой личный сайт-портфолио, который я создала в процессе изучения веб-разработки.

На сайте собрана информация обо мне, моих навыках и проектах. Я использую его как личную страницу, где могу показывать свои работы и постепенно добавлять новые.

## Используемые технологии

- HTML — структура сайта.
- CSS — оформление, адаптация под разные устройства и анимации.
- JavaScript — интерактивные элементы и эффекты.

## Особенности сайта

- Минималистичный дизайн в серо-белых оттенках.
- Стеклянные элементы (Glassmorphism).
- Адаптация под мобильные устройства.
- Анимации при прокрутке.
- Интерактивные кнопки и карточки.
- Блок социальных сетей.
- Музыкальный плеер.

## Структура проекта

```text
MyPortfolio/
├── index.html
├── style.css
├── script.js
├── README.md
├── images/
└── music/
```

## Запуск проекта

- Скачать или клонировать репозиторий.
- Открыть папку проекта в Visual Studio Code.
- Открыть файл index.html в браузере.
- Также сайт можно посмотреть онлайн через GitHub Pages.

## Планы на будущее

Проект ещё будет дорабатываться. В дальнейшем планирую добавлять новые работы, улучшать мобильную версию и пробовать новые возможности HTML, CSS и JavaScript.
